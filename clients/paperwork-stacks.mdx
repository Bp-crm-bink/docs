**Paperwork** (in the sidebar) reads scanned papers and files them for you. Usually each file is one client's papers. If you scanned several clients into **one file**, Paperwork can split it by person. You check the split before anything is uploaded.

<Note>
Paperwork is available to owners, admins and managers.
</Note>

## Choose how the papers were scanned

When you drop papers on Paperwork, you'll see two options:

<CardGroup cols={2}>
  <Card title="One file per person" icon="files">
    Each file is one client's papers. Drop as many files as you like. This is the usual way.
  </Card>
  <Card title="One file, several people" icon="layers">
    A run-on scan. BridgePoint finds where each person's papers start, and you check it before anything is sent.
  </Card>
</CardGroup>

You get both options for a **New client file**. For a DCF notice, MyACCESS page or enrollment papers, they only appear when you choose **Find them from the paper** as the client.

## Split a stack by person

<Steps>
  <Step title="Choose “One file, several people”">
    Then drop the stack. Everything you drop is read as one pile, in file-name order. A stack can have up to 300 pages.
  </Step>
  <Step title="Wait while each page is read">
    BridgePoint shows its progress as it works out whose papers each page is, for example "12 of 40 pages".
  </Step>
  <Step title="Check where each person starts">
    You'll see the page count and how many people were found. Each person shows their name, their page range and their date of birth if it was found. Click a person to list their pages, or click **View pages** to open them.
  </Step>
  <Step title="Fix the split">
    - **New person here** on a page starts the next person's papers on that page.
    - **Join with person N** puts that person's pages back with the person above.

    The first person always starts on page 1, and every page stays with someone.
  </Step>
  <Step title="Send the files">
    Click **Send N files**. Each person then goes on as their own file, the same as if you'd dropped one file per person.
  </Step>
</Steps>

<Warning>
Check any person with a warning before you send:
- **No name was found on these pages.** Open them and join them to the right person.
- **These pages show more than one family name.** Open them and check they belong to one client.
</Warning>

Nothing is uploaded until you click **Send**. If you click **Cancel**, or the stack can't be read, nothing is uploaded.

## Upload a whole folder

Under the drop area, click **Or choose a whole folder** to pick a whole scan folder at once. Each file in it still counts as one person unless you chose **One file, several people**.

## File limits

With **One file per person**, each file can be up to **20 MB** and **100 pages**. If a file is too big, the message tells you what to do. If it has several people, choose **One file, several people**. Otherwise, rescan it at 200 dpi or in black and white.

<Tip>
If a file you dropped as one person also has someone else's papers in it, Paperwork stops and changes nothing. The message names the other people it found. Drop the file again as **One file, several people** so it's split by person. For a notice, MyACCESS page or enrollment papers, choose **Find them from the paper** first.
</Tip>
