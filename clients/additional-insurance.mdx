Beyond the health-coverage programs tracked as [cases](/cases/overview), BridgePoint CRM lets you record a client's other insurance policies on their profile. The **Additional Insurance** tab keeps auto, dental, and homeowners coverage in one place so staff have a complete picture of what the client already carries.

Open a client profile and select the **Additional Insurance** tab. A segmented control at the top switches between the three policy types:

<CardGroup cols={3}>
  <Card title="Auto" icon="car" />
  <Card title="Dental" icon="tooth" />
  <Card title="Homeowners" icon="house" />
</CardGroup>

Each type shows the client's saved policies as cards. Use the add button to record a new policy, or edit an existing one. **Carrier** is the only required field on every form — everything else is optional so you can capture as much or as little as the client provides.

## Auto insurance

Records the client's vehicle coverage.

| Field | Notes |
| --- | --- |
| Carrier | Required |
| Policy number | Optional |
| Effective date | Optional |
| Cancellation date | Optional |
| Premium | Optional |

An auto policy can also hold associated **drivers** and **vehicles**, so you can record who is covered and what they drive under the policy.

## Dental insurance

Records standalone dental coverage.

| Field | Notes |
| --- | --- |
| Carrier | Required |
| Policy number | Optional |
| Member ID | Optional |
| Group number | Optional |
| Effective date | Optional |

## Homeowners insurance

Records the client's property coverage.

| Field | Notes |
| --- | --- |
| Carrier | Required |
| Policy number | Optional |
| Property address | Optional |
| Effective date | Optional |
| Cancellation date | Optional |
| Premium | Optional |
| Dwelling coverage | Optional |

<Note>
Additional Insurance is a record-keeping surface — these policies are separate from ACA and Medicaid **cases** and do not appear on the Cases board or in the ACA Pipeline. Editing a policy requires the same access as editing a client profile (Case Manager or above).
</Note>
